Orbital Mechanics

I’m learning orbital mechanics by coding it. I follow educational resources and write small programs to check that I understand each idea.

Status
Learning project
Technologies
Python, NumPy, Matplotlib

This is not a finished orbital simulator. It’s a set of exercises that I’m building up over time.

What I worked on

  • Equations of motion for a body under gravity.
  • Gravitational acceleration.
  • Numerical integration of the motion.
  • Plotting orbital trajectories.

What I’d do next

  • Compare different integration methods.
  • Move from simple two-body cases toward more realistic ones.
