Anduril AI Grand Prix, Round 1

This is a Python control system that flies a simulated drone through a gate course on its own. I wrote it for the Anduril AI Grand Prix Round 1 qualifier.

Status
Past competition project
Technologies
Python, NumPy, pymavlink
Links
Repository on GitHub

What I worked on

  • Generating the course path with Catmull–Rom interpolation.
  • Tracking a raceline through the gates.
  • Building a speed profile from curvature, acceleration and braking limits.
  • Feedback control to follow the profile.
  • MAVLink communication and telemetry.

Documented results

The repository documents one simulation run that completed all six gates in about 24 seconds with no recorded collisions. That is a simulation result only. I didn’t win the competition, and I’m not claiming to have officially qualified. The system is classical control and path planning, not a trained machine-learning model.

What I’d do next

  • Test against more varied courses.
  • Tune the controller more carefully.
